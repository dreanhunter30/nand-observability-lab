# NAND Observability Lab

Исследовательский инструмент для восстановления связей NAND по точным цифровым трассам и проверки, когда такое восстановление вообще однозначно. Python 3.10+, CPU, без установки зависимостей. Основной README.md — на английском; подробная оценка результатов — в REPORT_FINAL_RU.md.

## Быстрый запуск на Windows

Распакуйте архив, откройте терминал в папке проекта и выполните:

```powershell
py -3 nand_reconstruct.py examples/passive_ambiguous.json
py -3 nand_reconstruct.py examples/active_exact.json --output reconstructed.json
py -3 -m unittest discover -s tests -v
```

Первый пример обязан сохранить неоднозначность. Второй восстанавливает все шесть NAND. Настоящие связи лежат в отдельном файле для оценки и не передаются инструменту. Для своих измерений используйте тот же JSON-формат; нужны точные уровни всех первичных входов и всех выходов NAND в каждом отсчёте. Управляемые узлы указываются в `forced`.

Для полной серии:

```powershell
py -3 -S run_active.py
py -3 -S verify_active.py
py -3 -S run_blackbox.py
py -3 -S verify_blackbox.py
py -3 -S audit_release.py
```

Финальный основной результат воспроизведён: 8307/8307 правильных пар входов, 120/120 схем при полном доступе. При доступе к половине исполнительных узлов — 7631/8307 пар и 44/120 целых схем. Все внутренние сигналы в обоих случаях остаются наблюдаемыми.

Новый исчерпывающий опыт показывает предел внешних измерений: даже минимальную функцию «A И B И C» реализуют шесть разных схем из четырёх NAND. По всем восьми внешним входам их нельзя различить. Это предел информации в данных, а не недостаток перебора.

Архив содержит подготовленную MIT-лицензию, примеры, тесты, конфигурацию GitHub CI и полный отчёт. Локально выполнены проверки Linux/Python 3.12; Windows CI подготовлен, но ещё не выполнен. Сам импортёр не исправляет шум, не управляет приборами и не получает внутренние сигналы CPU/iPhone. Его 100% на идеальных сгенерированных трассах не переносятся автоматически на физическое оборудование.

Публиковать имеет смысл как открытый исследовательский прототип `nand-observability-lab`. Заявления об универсальном восстановлении процессоров, практическом аппаратном взломе или установленной научной новизне этим комплектом не подтверждаются.
